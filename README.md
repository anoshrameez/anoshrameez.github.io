# 🚀 Anosh - CMS Expert & Frontend Developer

Hi! I'm Anosh, a specialized **CMS Developer** with a focus on high-performance e-commerce and custom web solutions. I build fast, scalable, and visually stunning websites using **Shopify, WordPress, and Webflow**.

## 🌟 Key Features of this Portfolio

- **Smooth Scrolling:** Powered by Lenis for a premium feel.
- **Bento Grid Layout:** Modern project showcase with interactive hover effects.
- **Glassmorphism UI:** Clean, translucent design with Tailwind CSS.
- **Performance Optimized:** GSAP animations for smooth, lag-free transitions.

## Tech Stack & Tools

## 🛠️ Tech Stack & Tools 

- **CMS:** Shopify (Liquid), WordPress (Elementor, Breakdance, Divi), Webflow.
- **Frontend:** HTML5, CSS3 (Sass), Tailwind CSS, JavaScript (ES6+).
- **Backend:** PHP, Laravel (Basics).
- **Animations:** GSAP (ScrollTrigger).
